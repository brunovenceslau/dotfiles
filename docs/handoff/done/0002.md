# conf(ghostty): Add new themes

PR #69 (conf(ghostty): Add new themes) added Ghostty colour themes under
`config/ghostty/themes/`, with licensing that passes the `reuse` gate. Merged
as 9b76f23. The themes are catppuccin (frappe, latte, macchiato, mocha),
gotham, gruvbox (dark, light), rose-pine (dawn, default) and srcery.

Each file names its upstream copyright holder and licence, and
THIRD-PARTY-NOTICES.md records each upstream. `tests/ghostty_test.sh` checks
every theme. Gates: three ship rounds (the ship gate is the pre-merge review
by reviewer and security personas), hosted CI green. Not covered: Ghostty
itself was not installed, so no theme was loaded. The three items left open
are in pending/ (`ghostty-test-message`, `ghostty-allowlist-breadth`,
`gotham-autosuggest-contrast`).
